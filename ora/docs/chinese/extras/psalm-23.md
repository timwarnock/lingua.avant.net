# 聖詠第二十三篇

     data-prayer="psalm-23"
     data-json="psalm-23.json"     data-show-phonetic="true"></div>

<div class="prayer-fallback" markdown="1">

**中文**

達味詩歌。 上主是我的牧者， 我實在一無所缺。 他使我臥在青綠的草場， 又領我走近幽靜的水旁， 他使我的心靈蘇醒， 為了自己的名 導我踏上了正義的坦途。 縱使我應走過陰森的幽谷， 我不怕兇險， 因你與我同在。 你的牧杖和短棒， 是我的安慰勇往。 在我對頭面前， 你為我擺設了筵席； 在我的頭上傅油， 使我的杯爵滿溢。 在我一生歲月裏， 幸福與慈愛常隨不離； 我將住在上主的殿裏， 直至悠遠的時日。
